This update is mainly to support old Minecraft versions so that server owners have more options and I don't have to repeatedly explain why they were not supported. 
For current 1.16+ servers, this is just a Quality-of-Life update with no breaking change.
For all users, enjoy the update.

- **Add XSeries back to support old format of Item Material**
  - This means the current Material names were only used in post-1.13 can now be used in older versions.
- **Change the default GUI config to always use legacy color code**
  - Current hex color usage is not affected.
- **Add the old break-then-item-spawn check for drop detection in older versions**
